# 57exercises

This repo contains implementations of exercises from the PragProg book ["Exercises for Programmers"](https://pragprog.com/titles/bhwb/exercises-for-programmers/).

These exercises are generally worked on as I try to get some experience in a new language or paradigm. To that end they may not represent best practices. When they are complete I will generally not go back to them so they may not be up to date with the latest standards and libraries. Caveat Emptor.
